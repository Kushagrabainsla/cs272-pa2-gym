# Courier Route Environment

## Story

The agent controls a courier on a 7 by 7 warehouse floor. The courier starts at
the depot in the upper-left corner. It must first reach the package checkpoint
in the center, then carry the package to the delivery destination in the
lower-right corner. The episode ends when the delivery is complete.

## Environment ID and constructor

Importing `myenv.py` registers the environment as `cs272/CourierRoute-v0`.
Create it with:

```python
import gymnasium as gym
import myenv
env = gym.make("cs272/CourierRoute-v0", render_mode="ansi")
```

The constructor accepts `render_mode`, which can be `None` or `"ansi"`. The
registered time limit is 100 steps.

## Observation space and encoding

The observation space is `Discrete(98)`. There are two stages and 49 positions.
Stage 0 means that the package has not been collected. Stage 1 means that it
has been collected. A position is `(row, column)`, with both coordinates from
0 through 6. The exact encoding is:

```text
state = stage * 49 + row * 7 + column
```

The initial observation is 0, which represents stage 0 at `(0, 0)`. The
delivery destination is `(6, 6)` in stage 1.

## Action space

The action space is `Discrete(4)`:

| Action | Direction | Movement |
|---:|---|---|
| 0 | Up | `(-1, 0)` |
| 1 | Right | `(0, +1)` |
| 2 | Down | `(+1, 0)` |
| 3 | Left | `(0, -1)` |

Movement outside the floor is clipped to the nearest boundary cell.

## Transition noise

Each action is executed in the requested direction with probability 0.85. With
probability 0.15, it slips to one of the two perpendicular directions, each
with probability 0.075. The random choice is generated by `self.np_random`,
which is seeded by `reset(seed=...)`.

## Rewards

Every step gives `-0.02`, encouraging short routes. Entering the checkpoint for
the first time gives an additional `+1.0`. Entering the destination after the
package has been collected gives an additional `+10.0` and ends the episode.
The checkpoint is not terminal because the courier still has to deliver the
package.

## Starting, termination, and truncation

Every reset starts at `(row=0, column=0, stage=0)`. The environment returns
`terminated=True` when the courier reaches `(6, 6)` in stage 1. It never sets
`truncated=True` itself. Gymnasium's `TimeLimit` wrapper sets truncation after
100 steps if delivery has not occurred.

## Rendering

With `render_mode="ansi"`, `render()` returns a text map. `@` is the courier,
`C` is the uncollected checkpoint, `D` is the destination, `S` is the depot,
and `.` is an open cell.
